# Y Combinator Landing Page Clone

This is a responsive HTML and CSS recreation of a Y Combinator-style landing page. The project started as one of my early frontend practice builds, and it was later improved to make it more polished, responsive, and portfolio-ready.

## What Was Improved

- Rebuilt the layout with responsive CSS instead of fixed spacing and negative positioning.
- Added tablet and mobile breakpoints so the page adapts across different screen sizes.
- Improved the hero section so the text, image, and statistic cards work on desktop and mobile.
- Added a hamburger menu for smaller screens to prevent the navbar from wrapping awkwardly.
- Made the company logo grid, content cards, video sections, and footer responsive.
- Cleaned up parts of the HTML structure, including the stylesheet link placement and button/list markup.
- Fixed spacing, alignment, and overflow issues that caused sideways scrolling on mobile.

## Built With

- HTML5
- CSS3
- Responsive design with media queries

## Project Purpose

The goal of this project is to show growth from an early static layout into a more responsive, portfolio-friendly webpage. It focuses on layout structure, responsive design, visual consistency, and improving an existing codebase without changing the original concept.
